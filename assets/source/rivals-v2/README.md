# OathFront hero art, rivals-v2

Six original hero illustrations generated for the user-requested redesign with the built-in image_gen tool. `generation.json` preserves the exact prompts and generated source paths; `source-audit.json` records copied source hashes, alpha measurements and the controller's visual review. Original outputs remain in their generation directory; project-bound copies are under `heroes/`.

The shared direction is expressive contemporary comic fantasy: angular armor, dramatic colored rim light and distinct silhouettes. Marvel Rivals is the visual reference, not a source of copied characters, logos or assets. Each hero corresponds to an existing immutable gameplay ID; this is a presentation asset version, not a rules/content version.

`fivefold-board.png` is the shared comic battlefield background, with original generation prompt/source/hash in `board-generation.json`. Its center is deliberately quiet for the five-lane DOM/Pixi overlay. It replaces only the shared board illustration in the presentation layer; the eight existing Location strips remain supported.

Use full-figure contain framing for character stages, with a small layout margin. Some decorative tips approach source edges. Small HUD/roster images need deliberate face/upper-body framing derived from the same illustration; never stretch the portrait to a square. Preserve alpha during asset export. Do not serve original multi-megabyte PNGs as every small thumbnail.

Generated game artwork is part of the OathFront project. The image generator provides no separate third-party stock-art license file; do not label these illustrations as Marvel-provided or claim independent human authorship.
