# Moonroot groundcover material

Generated with built-in `image_gen.imagegen` on 2026-10-23. The approved [Moonroot v3 concept](../../../../docs/design/concepts/moonroot-battlefield-v3-concept.png) was inspected for the cool jade/olive foliage palette only. It was not a generation input or runtime texture. This original orthographic material contains small ivy leaves, detailed moss and sparse tiny fern tips, with an irregular silhouette and genuine alpha. It contains no scene geometry, figures, objects, UI or cast shadows.

The initial generation had insufficient visible margin on one edge. One built-in edit reduced the patch while retaining its botanical detail. Both native 1254×1254 RGBA PNGs are preserved byte-for-byte in `masters/moonroot-groundcover-initial.png` and `masters/moonroot-groundcover.png`. Exact initial and edit prompts are in `prompts/moonroot-groundcover.txt` and `prompts/moonroot-groundcover-margin-edit.txt`. Returned source paths are recorded in `generation/groundcover-tool-results.json`; exact prompts, SHA256 values, dimensions, bytes and alpha statistics are in `generation/groundcover-provenance.json`.

The shipped material is `apps/web/public/assets/arenas-v2/materials/moonroot-groundcover.webp`: **512×512 RGBA, 61,622 bytes**, SHA256 `28b12eb36d274a0795ee1d0e5f5143c0fea7c73fd6af402ad45a574cf6c5a85c`. Complete decoded RGBA mipmaps occupy **1,398,100 bytes (approximately 1.33 MiB)**.

Use **alphaTest 0.38**. Visible runtime alpha-test bounds are `[96, 104, 424, 412]`, leaving at least 17.19% clear margin on every side. The generator also supplied a tiny alpha=1 fringe: seven pixels in the outer 10% border have alpha 1/255. These are retained rather than repaired and are removed by the alpha test. Therefore the border is clear at the material's alpha cutoff, not mathematically alpha zero everywhere. Pixels with alpha at least 2 remain within `[93, 101, 427, 415]`. No rectangular edge is visible in the inspected image.

Reproduce with `python assets/source/arenas-v2/materials/generation/prepare_groundcover.py` from the repository. This standalone addendum follows the existing Pillow conversion workflow: uniform LANCZOS resize, WebP quality 86 / method 6, alpha quality 100 and exact mode. It verifies source hashes, runtime format/dimensions, lossless preservation of the resized alpha, visible margin and transfer/decoded memory bounds. There is no cropping, recoloring, compositing, mask repair or invented relief map. It writes only this groundcover's runtime and provenance.

The initial generation, final native output and 512-square runtime were visually inspected. Fine ivy veins, ragged leaf outlines, moss and sparse fern tips survive the runtime reduction. This is a single cutout patch, not a tiling texture. Use a full-image UV island on each authored groundcover patch. Lit 3D appearance, UV density, overlapping cutouts and scene integration remain the renderer/model verification gate.
