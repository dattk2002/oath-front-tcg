# OathFront hero expansion — original source artwork

Fourteen original hero concepts generated with the built-in `image_gen` tool for this project. These assets are a **design collection**, not active runtime catalog content.

- `heroes/*.png`: fourteen final 1024×1536 RGBA images, copied byte-for-byte from tool output.
- `manifest.json`: original filename, SHA256, size, alpha measurements and review notes.
- [Character bible](../../../docs/design/heroes-expansion/README.md) and [exact prompts](../../../docs/design/heroes-expansion/prompts.json).
- [Local visual gallery](../../../docs/design/heroes-expansion/gallery.html): inspect genuine transparency over the Pen lilac/slate palette.

The official Marvel Rivals website informed broad visual presentation and angular comic shape language. No Marvel character artwork, logos or extracted assets are included. Names, equipment and story concepts belong to the original OathFront design brief. AI-generated provenance is recorded; this manifest is not a third-party rights certificate.

Do not use these full source PNGs directly in a production grid. Before playable integration, export bounded WebP/AVIF variants with manifest hashes, reserve layout dimensions, review portrait focal points and retain a padded contain version for profiles. The requested 8% image margin was not consistently generated; solid-alpha bounds remain inside every canvas. Preserve alpha when exporting.

No image pixels were edited after generation. No background-removal script, model fallback or external API credential was used.
