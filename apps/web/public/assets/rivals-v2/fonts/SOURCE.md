# Barlow Condensed

Downloaded from the official Google Fonts repository, revision `60824dce48f7dd28fe7d65559f2da1f6e04e585b`, directory `ofl/barlowcondensed`. Files are original Bold700, ExtraBold800 and Black900 TrueType fonts, with the accompanying SIL Open Font License retained as `OFL.txt`.

Source: https://github.com/google/fonts/tree/60824dce48f7dd28fe7d65559f2da1f6e04e585b/ofl/barlowcondensed

Use locally hosted web derivatives for display headings; keep the existing Noto Sans for body and user-provided Unicode names. This is an open-license condensed alternative chosen for OathFront, not RefrigeratorDeluxeBold and not a font downloaded from the Marvel Rivals website.
